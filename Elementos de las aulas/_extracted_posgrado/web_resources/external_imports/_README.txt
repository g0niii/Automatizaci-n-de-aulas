External Imports README from Cidi Labs DesignPLUS

This folder was created by DesignPLUS when an external file was uploaded into this course.  

You cam move or rename the files in this folder without affecting them in the course.  

You can also move or rename this folder if you wish, but if additional external files are imported into the course, an "external_imports" folder will be created again.

Since the files in this folder were imported from external sources, please be mindful of any copyright limitations and/or accessibility support obligations associated with the file.

Files that came from outside the LMS have a timestamp in the filename to avoid duplication.
